Refresh the example data

One button deletes the old example data and writes a fresh set dated around today, so the dashboard, the lab portal and the news timeline all line up for a demo. Only records marked as example data (demo: true) are touched; real reports are never deleted.

What to refresh

Sign in with an account listed in firestore.rules (isLabUploader for the surveillance data, isClinician for the lab data).

No database? No problem

The demo on the start page also works without this step: if the database can't be reached, the app builds the same example data in your browser for that visit.
