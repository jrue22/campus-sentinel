Wastewater test results

Paste or upload a CSV from the treatment facility's lab. Columns, in this order, with a header row:

date,site,target,copies_per_l,pmmov_copies_per_l

Dates are YYYY-MM-DD (the sample date, not the lab report date). site and target must be ids from wastewater-config.js. Use 0 for a non-detect. pmmov_copies_per_l is optional but recommended; include it for every row or for none. Samples already in the database are skipped, so uploading the same file twice is safe. Do not include any personal or facility-confidential data: this database is publicly readable.

SARS-CoV-2 lineages (sequencing)

Lineage shares for each sample, as estimated by Freyja from sequencing reads. One row per lineage, with a header row:

date,site,lineage,abundance

abundance is a fraction from 0 to 1, as Freyja reports it; a sample's rows should add up to about 1. Freyja's aggregate output lists a sample's lineages and abundances on one line, separated by spaces: put each pair on its own row here, with that sample's date and site.
